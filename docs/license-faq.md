# License FAQ

Pattern-lang ships under the [Business Source License 1.1](../LICENSE). Plain-English answers below.

## Can I use it for free?

Yes, if any of the following applies:

- You use it for **non-commercial** purposes (personal projects, education, demos).
- You use it **internally** in an organisation with **annual revenue under USD 1M**.
- You use it for **security research, academic research, or independent verification** of joule receipts.

No payment, no registration, no contact required.

## Can I redistribute the binaries?

You can run them. You can share the official download link. You cannot rehost or re-sell the binaries themselves under the BSL grant. Mirror through GitHub Releases.

## Can I see the source?

The source is at [openIE-dev/pattern-lang-core](https://github.com/openIE-dev/pattern-lang-core), which is private. Pattern-lang is free to use software, not an open-source project. For source access for research or integration work, contact [openie.dev](https://openie.dev).

## What's the Change Date?

Four years after each binary's release date — declared on the corresponding release page. On the Change Date, that binary converts to Apache-2.0.

So every release has its own clock. Today's binary becomes Apache-2.0 four years from today. Tomorrow's binary's clock starts tomorrow.

## What about the documentation in this repo?

[CC-BY-4.0](https://creativecommons.org/licenses/by/4.0/). Copy, adapt, redistribute — attribute Open Interface Engineering.

## What if my use doesn't fit the Additional Use Grant?

If you're a commercial entity over the revenue threshold and you want to use pattern-lang in production, you need a commercial licence. Reach out via [openie.dev](https://openie.dev) — the standard terms are simple and the conversation is short.

## Why BSL, not Apache?

OpenIE's commercial model is to give the architecture away publicly, sell the operational substrate, and let the binary convert to a permissive licence on the four-year horizon. BSL is the standard licence that supports that.
